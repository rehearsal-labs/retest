A platform-encoded recording is not offered as a frame source and is not called a live frame stream. All native executor, simulator, recorder and service launches were closed through their recorded owners. Runtime logs were copied before temporary fixture cleanup.

Screenshot loops are always named `screenshot-loop`. Every source supplies its session identity and whole arrival microseconds on the run clock. `clockMapping` records `timestamp: 'run-arrival'`, `targetClock: 'not-used'` and the uncertainty interval. `earliestUs` is request time for a screenshot and source start for a screencast. A target timestamp is never substituted for the run clock. These fields describe when pixels might have been read, not a proven paint time. `recordSource` refuses invalid clocks, intervals, ordering, identities and sizes.

Suspension suppresses screenshot requests and counts withheld ticks. Withheld delivered frames and stretches stay separate from dropped frames. Interval overlap keeps a capture requested before a secret stretch withheld even if it arrives after resume. Loss is checked even while withheld. An unanswered grab stops further requests; it does not prove a remote operation was undone or the app died. Sources report a named ending and loss gap. Start and stop have independent bounds. Cleanup after an uncertain screencast start is awaited by stop within its bound; a refusal or unknown end remains in final stats. No source sends input.

The capture adapters preserve the target's encoded bytes. Since 9 October 2026 the macOS driver no longer cuts the display: the window server draws the app's own window from its window number, Retest hands over the PNG it wrote, and that needs Screen Recording for the terminal or agent that runs Retest; the rest of this paragraph records the display cut it replaced. The existing macOS driver remains an end-to-end exception: it decodes a display PNG, cuts the checked owned window, then encodes another PNG. That driver boundary violates the brief's encoded-frame requirement and is called out in the report. The full display is never forwarded as the app's recording. The real Mac refusal is retained verbatim in `native-artifacts-2/macos-refusal.json`; the covering app was not moved or ended and the coverage check was not bypassed. A Screen Recording route is not offered or requested; it would need a non-prompting, already-granted permission preflight and the same coverage safety.
