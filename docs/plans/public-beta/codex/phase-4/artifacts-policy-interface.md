Artifacts, retention, pixel policy and HTML escaping: the exported signatures as the artifacts-policy lane settled them. This note is for the other Phase 4 lanes; the source files are the truth, read them fresh.

src/store/artifacts.ts
- `artifactPath(spec: ArtifactSpec): string`. `spec` is `{ kind: 'screenshot', identity: RecordIdentity, purpose: 'failure' | 'evaluation', sequence, format: 'png' | 'jpeg' }` | `{ kind: 'thumbnail', identity, of: { kind: 'screenshot', purpose, sequence } | { kind: 'recording', sequence }, format }` | `{ kind: 'recording', identity, sequence, container: 'mp4' | 'webm' }` | `{ kind: 'frames', identity, sequence, index, format }` | `{ kind: 'diagnostics', identity }` | `{ kind: 'report' }`. Layout: `artifacts/<attempt>/<app-slug>/screenshot-failure-1.png`, `recording-1.mp4`, `frames-1/000007.jpg`, `thumbnail-recording-1.jpg`; `diagnostics/<attempt>.<app-slug>.jsonl` (flat, so the run store's diagnostics redaction still reaches it); `report.html`. Throws `RangeError` if `sessionId` is not `formatSessionId(attemptId, app)`.
- `recordingOutput(identity, sequence): string` (the stem for the media process start, no extension). `ArtifactSequences#next(identity, 'failure' | 'evaluation' | 'recording' | 'frames'): number`.
- `referenceProblem(reference): string | undefined`; `portableReference(runFolder, absolutePath)`; `resolveReference(runFolder, reference)`; `createArtifactFolder(runFolder, reference)` (makes parent folders, refuses links). Each returns `{ ok: true, ... }` | `ArtifactRefused { ok: false, reference, reason, message }`.
- `ArtifactRefusal = 'invalid_reference' | 'missing' | 'symbolic_link' | 'outside_run_folder' | 'hard_link' | 'not_regular_file' | 'too_large' | 'changed' | 'unreadable'`.
- `readArtifactFile(runFolder, reference, { maxBytes })`: `{ ok: true, reference, path, bytes: Buffer }` | `ArtifactRefused`. Two steps for streaming: `checkArtifact(runFolder, reference, { maxBytes })` gives `{ ok: true, artifact: CheckedArtifact }`; `artifact.open()` gives `{ ok: true, file: OpenedArtifact { descriptor, size, read(), close() } }` | `ArtifactRefused`.
- `eventArtifactReferences(events)`, `resultArtifactReferences(result)`: `ArtifactReference[] { path, kind, namedBy, testId?, attemptId?, app?, sessionId?, evidenceOf?: 'evaluation', of? }`. `inventoryArtifacts(runFolder, references, { maxEntries? })`: `{ present, missing (with reason), unreferenced (partial flag), refused, truncated }`.
- Retention: `RetentionRules { recordings: 'all' | 'failures' }` (`defaultRetentionRules` keeps all); `RetentionMoment { kind: 'attempt_finished', attemptId, status } | { kind: 'run_finished' }`; `planRetention({ moment, rules, references, inventory }): RetentionPlan`; `applyRetention(runFolder, plan, { removing(record), failed(record) }): RetentionOutcome`. `removing()` is called before each unlink, so the event is written first.
- Proposed events (types exported as `ArtifactRemovedRecord` and `ArtifactRemovalFailedRecord`): `artifact.removed { path, kind, reason: 'passed_attempt_recording' | 'thumbnail_of_removed' | 'lost_recording_partial', moment, bytes, testId?, attemptId?, session?, sessionId? }` and `artifact.removal_failed { the same without bytes, message }`.

src/media/policy.ts
- `AppPixelRules { screenshots, recordings: 'allowed' | 'never' }`; `defaultAppPixelRules`; `appPixelRulesSchema` (for the config); `appPixelRules(input)`.
- `fieldMasking(fact: FieldFact): FieldMasking`. `FieldFact = { kind: 'web', engine, element: 'input', inputType } | { kind: 'web', engine, element: 'textarea' | 'editable' | 'other' } | { kind: 'native', platform: 'ios' | 'macos', elementType } | { kind: 'unread', reason }`. Masks only: a web input of type password (Chromium, Firefox, WebKit) and a macOS secure text field; an iOS secure text field is treated as showing text.
- `new PixelCapturePolicy({ rules: (app) => AppPixelRules, clock: () => runClockMicroseconds, record?: (PixelPolicyRecord) => void })`, one per run. `decide({ identity, use: 'failure' | 'evaluation' | 'agent' | 'recording' | 'live', source: CaptureSourceName, span?: { earliestUs, arrivedUs } })`: `{ capture: true }` | `{ capture: false, withheld: 'app_rules' | 'secret_entry', message }`. `beginSecretEntry({ identity, secret: name, field: driverKey, fact })` just before the first key; `endSecretEntry(entry, { fact, input: 'not_sent' | 'sent' | 'unknown' })`; `fieldChanged(identity, field, 'gone' | 'empty' | 'masked')`; `pageLeft(identity, 'new_document' | 'session_ended')`; `stretches()`.
- A capture is withheld when its span overlaps a stretch. For a screencast frame, `earliestUs` is when the screencast last started, so after a stretch the recording-runner must restart the screencast to resume (a screenshot loop passes each tick's request time). A window crop is withheld while any session in the run is withheld.
- Proposed events: `capture.withheld { session, sessionId, testId, attemptId, secret (name), cause, fromUs, exposedFromUs? }`, `capture.resumed { ..., endedBy, fromUs, untilUs }`, `capture.masked_entry { ..., atUs }`.

src/reporters/html/escape.ts
- `escapeHtml(text)`: for text and quoted-attribute positions. `pageHref(url): string | undefined` (http and https only, no credentials). `artifactHref(reference): string | undefined` (portable references only). `scriptJson(value: JsonValue)`: for a `<script type="application/json">` block.
