## Native withholding opt-in

Native secret entry keeps pixels by default: secure fields rely on the platform's dots and required masked read-back, while plain fields may show characters in screenshots or video. Set `recording: { nativeWithholding: true }` or the overriding environment variable `RETEST_NATIVE_WITHHOLDING=true` to enable the earlier plain-field withholding and guarded resume; secure fields never withhold in either mode.

`RETEST_NATIVE_WITHHOLD_RESUME` is removed because the opt-in includes resume. Failed reads, cancellation, uncertain identity, a focused field or exposed text keep an enabled stretch open. Clearance requires the same unfocused field masked or empty, the verified filled field absent from a fresh owned tree after a completed fill, or its owned window gone, and no software keyboard on iOS. Nothing changes an action's failure or unknown outcome.

The additive version 1 `capture.native_entry` event records the selected branch without the value. Native `capture.masked_entry.readBack: length_matched` records only successful secure verification. Current readers accept old folders; old strict readers refuse the new event or field.
