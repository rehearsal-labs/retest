Lane "html-report": the HTML evidence report. Phase 4 item 7 of docs/plans/public-beta/release-0.1.0.md, with the report parts of items 5 and 9. Read docs/plans/public-beta/codex/phase-4/common.md first; it binds this lane.

What exists: a run folder with `events.jsonl` and `result.json` (src/store/**, the rebuilt result in src/store/rebuild-result.ts), the terminal reporter and its failure card (src/reporters/human*.ts, failure-card.ts, code-frame.ts, diff.ts), the JSONL reporter, the diagnostics report (src/diagnostics/report.ts) and the evaluation records (src/evaluation/report.ts, src/protocol/evaluation.ts), `retest inspect` (src/cli/inspect/**). No HTML report exists.

Deliver a static HTML report written into the run folder, on request (`--reporter html` on a run, and a command that builds it from an existing run folder), generated only from the events and the result:
1. One self-contained file: no server, no network request, no external font, script or stylesheet; media referenced by portable paths inside the run folder, so the folder can be moved or zipped and still open. It opens from a `file://` address.
2. Content, per run and per test: outcome and evidence status as two separate facts; target identity (engine, build, platform, app); source location with the code frame; expected and actual values with the diff; the action and check timeline of each app; screenshots with thumbnails; the recording of each app with the timeline laid over it, a click on a step moving the video to its time through the recorded clock mapping; console and network views from the diagnostics artifacts with their capture status; AI checks with each criterion's verdict, the short evidence citations, the provider and model identity, usage, and warnings; replay facts and fingerprints. Missing, dropped, withheld and incomplete evidence is named where the evidence would have been, never left as an empty space. An interrupted or incomplete run produces a report that says so.
3. Safety: every piece of app text, test title, URL, console line, network value and model answer is untrusted. It is escaped through the helper in src/reporters/html/escape.ts (the artifacts-policy lane writes it; until it lands, build against its agreed signature: one function for text and attribute positions, one for URLs), never inserted as markup, never executed; a restrictive content security policy in the file; links to artifacts only through the safe portable references; artifacts read only through the safe read in src/store/artifacts.ts. Test with hostile titles, texts, URLs and console lines (script tags, attribute breakouts, `javascript:` links, markup in model answers).
4. Agreement: terminal, JSONL and HTML state the same outcome facts for the same run folder, including failed, skipped, not run, interrupted and incomplete runs; one test compares the three on a set of run folders, among them folders written by a reader-refusing older shape if any exist in the fixtures.
5. Looks: plain, readable and calm, light and dark from the system setting, usable at a narrow width, keyboard reachable, no decoration that carries no information. It is a tool for reading a failure quickly: the failing check, its values and its picture come first.
